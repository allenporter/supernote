# Rapid Logging & Transcription Guidelines

Rapid logging is the language of the bullet journal method. You must transcribe the handwritten notes literally and preserve all rapid logging symbols and page structures.

## Rapid Logging Symbol Mapping
Map the hand-drawn symbols on the page to the following text representation:
- **Incomplete Task**: Start the line with `•` (Unicode bullet `\u2022`).
- **Completed Task**: Start the line with `X` (capital X).
- **Migrated Task (Forward)**: Start the line with `>` (greater-than).
- **Migrated Task (Back/Scheduled)**: Start the line with `<` (less-than).
- **Event**: Start the line with `o` (lowercase letter o).
- **Note / Information**: Start the line with `-` (hyphen/dash).
- **Critical / Starred Signifier**: If a star or asterisk is drawn next to an item, prefix it with `* ` (e.g., `* • critical task` or `* X completed critical task`).

## Transcription Formatting Rules
1. **Do Not Rephrase or Summarize**: Write down the exact words written. Do not correct grammar, do not expand abbreviations, and do not add conversational explanations.
2. **Preserve Layout and Indentation**: If items are indented (nested under a parent item), use two spaces `  ` per indentation level to preserve the hierarchical relationship.
3. **Preserve Line Structure**: Try to map line breaks in the handwritten note to line breaks in the transcript.
4. **Strikethrough / Cancelled Items**: If text or tasks are crossed out, wrap them in double tildes: `~~crossed out text~~`.
5. **No Conversational Filler**: Output ONLY the raw transcript of the handwritten text. Do not output intro/outro sentences like "Here is the transcription...".
